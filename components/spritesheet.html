Spritesheet Component

render multi sprites for animation of an entity.

Properties

Name Type Description
layer int high layer up on low layer
color Color texture color from rgba
flipX bool flip dir horizontal sprite render
flipY bool flip dir vertical sprite render
currentFrame int current number frame from all frames count animation
playing bool is Playing current Animation
currentAnimation string animation name is playing now

Functions

Function Description
Play(string) start play animation by name from begin
Stop() End current animation playing now if play again restart animation
Pause() Pause current animation for sometime
Resume() Return play current animation not from begin
GetCurrentTextureName() Return current texture name from current Animation

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new spritesheet component. 
local spritesheet = entity:AddComponent(Spritesheet())

-- access the spritesheet properties
spritesheet.currentFrame = 1;
spritesheet.currentAnimation = "walk";
spritesheet.layer = 2
spritesheet.color = Color(255, 0, 0, 255)--red
spritesheet.flipX = true

if spritesheet.playing then
    DebugLog(is playing animation)
end

spritesheet:Play("idle")
spritesheet:Stop()
spritesheet:Pause()
local texture = spritesheet:GetCurrentTextureName()

Spritesheet Component

المتغيرات

المتغير النوع الوصف
layer int الطبقة الرقم يحدد اولوية العرض
color Color لون الصورة
flipX bool لعكس الصورة بشكل افقي
flipY bool لغكس الصورة بشكل عامودي
currentFrame int رقم الاطار الحالي من عدة اطارات
playing bool اذا كان صحيح فان الحركة قيد التشغيل اما العكس غير صحيح الحركة واقفة
currentAnimation string اسم الحركة الحالية قيد التشغيل

الدوأل

اسم الدألة الوصف
Play(string) لعداة تشغيل بداء الحركة من الاسم الحركة
Stop() اقاف تشغيل الحركة الحالية بشكل نهائي
Pause() اقاف تشغيل الحركة الحالية مؤقت
Resume() استمرار تشغيل الحركة الحالية كسابقا
GetCurrentTextureName() اعاد اسم الصورة الحالية من الحركة الحالية
