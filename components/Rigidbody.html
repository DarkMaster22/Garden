Rigidbody Component

Physics body in world with any shape Collider

BodyType

type physical body in world

enum

Static Kinematic Dynamic

Example


BodyType.Dynamic

Properties

Name Type Description
bodyType BodyType body type if static never move or dynamic mover physical
fixidRotation bool active rotation physical

Functions

Function Description
LinearImpulse(Vec2 impulse) add impulse from position and wake
ApplyForce(Vec2 force) add force to center and wake
ApplyLinearImpulse(Vec2 impulse) add impulse to center and wake
ApplyTorque(float torque) give torque wake
AngularImpulse(float impulse) angular or rotate by impulse wake
SetLinearVelocity(Vec2 velocity) set velocity to mover physical
GetLinearVelocity() return body velocity
SetAngularVelocity(float angularVelocity) set angular velocity to angular or rotate physical
GetAngularVelocity() return angular velocity
SetGravityScale(float gravity) set gravity local object
SetTransform(Vec2 position, float angle) move and rotate object not physical

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new Rigidbody component at . bodyType, fixidRotation.
local rb = entity:AddComponent(Rigidbody(BodyType.Static, true))

-- access the Rigidbody properties
rb.bodyType = BodyType.Dynamic
rb.SetLinearVelocity(Vec2(5, 0))

Rigidbody Component

اي كولايدر لن يتفاعل من دونه. يتحكم في transform الكائن لجعل جسم فيزيائي

BodyType

نوع جسم الفيزيائي

enum

Static Kinematic Dynamic

مثال


BodyType.Dynamic

المتغيرات

اسم المتغير النوع الوصف
bodyType BodyType تحديد نوع جسم الفيزيائي
fixidRotation bool تفعيلة لن يدور فيزيائي

الدوأل

الدالة الوصف
LinearImpulse(Vec2 impulse) يدفع الجسم بقوة معينه من موقع الكائن
ApplyForce(Vec2 force) اضافة قوة للجسم لتحريكة من مركزة
ApplyLinearImpulse(Vec2 impulse) يدفع الجسم بقوة معينه من مركز الكائن بدل موقعه
ApplyTorque(float torque) اضافة عزم دوران
AngularImpulse(float impulse) دفع زاوية للجسم بقوة معينه
SetLinearVelocity(Vec2 velocity) تعيين تسارع الجسم
GetLinearVelocity() يعود بي قيمة تسارع الجسم
SetAngularVelocity(float angularVelocity) تعيين سرعة زاوية
GetAngularVelocity() يعود بي قيمة سرعة زاوية
SetGravityScale(float gravity) تعيين قوة سحب الجاذبية للجسم فقد
SetTransform(Vec2 position, float angle) تعيين موقع و دوران الكائن من transform خارج فيزاته

مثال


-- انشاء كائن جديد
local entity = Entity("name", "group")

-- اضافة مكون جديد Rigidbody. BodyType, fixidRotation.
local rb = entity:AddComponent(Rigidbody(BodyType.Static, true))

-- access the Rigidbody properties
rb.bodyType = BodyType.Dynamic
rb.SetLinearVelocity(Vec2(5, 0))
