Entity Registry

Registry

registry haved all entities in the world

Functions

Function Description
GetEntities() get all entities haved
FindEntityByName(string) every entity have name special. search in entities haved this name and return
FindEntitiesByGroup(string) return entities haved this group
Clear() rest from zero this registry equal empty

Example


local player = Registry.FindEntityByName("Player")--entity

local coins = Registry.FindEntitiesByGroup("Coins")--entities

for i, entity in paris(Registry.GetEntities()) then -- loop foreach all entities per entity
    DebugLog("entity name : ", entity:name())
end

Registry.Clear()--clear or rest

Registry

يدير جميع كائنات المشهد

الدوال

الدالة الوصف
GetEntities() يجلب جميع كائنات المشهد
FindEntityByName(string) يبحث عن كائن حسب اسمه
FindEntitiesByGroup(string) يبحث على جميع الكائنات يحملن نفس اسم القروب
Clear() يحذف جميع الكائنات المشهد او يعود من الصفر

مثال


local player = Registry.FindEntityByName("Player")--كائن اسمه Player

local coins = Registry.FindEntitiesByGroup("Coins")--كائنات دخل قروب Coins

for i, entity in paris(Registry.GetEntities()) then -- يمر على جميع الكائنات كائن كائن
    DebugLog("entity name : ", entity:name())
end

Registry.Clear()--يحذف جميع الكائنات المشهد ليعود من نقطة الصفر
