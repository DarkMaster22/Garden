CameraComponent

controls camera for view the world

Properties

Name Type Description
scale float set zoom or range view camera
landscape bool change view camera landscape or portable

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new CameraComponent component at.
local camera = entity:AddComponent(CameraComponent())

-- access the CameraComponent properties
camera.landscape = false
camera.scale = 0.5
