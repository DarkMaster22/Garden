SoundSource Component

listener music or sound for player

Properties

Name Type Description
sound string sound name for get file sound.mp3/wav for current sound
playOnStart bool for play sound on start

Functions

Function Description
Play() to play current sound listener
Stop() to stop or end play current sound listener
Pause() puase current sound listener for sometime
Resume() resume sound listener in current sound before
SetPitch(float pitch) set pitch or speed listener
SetVolume(float volume) range volume sound listener between 0-1
SetLoop(bool loop) set looping on start play again infinite until end scene or false loop
GetPitch() return pitch or speed from sound source
GetVolume() return volume from sound source
IsLooping() check if turn loop
IsPlaying() check if playing sound source
IsPaused() do it paused sound source for sometime

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new SoundSource component at . sound, playOnStart.
local listener = entity:AddComponent(SoundSource("sound.mp3", true))

-- access the SoundSource properties
listener.sound = "music.wav"
listener:Play()
listener:SetVolume(0.8)
local pitch = listener:GetPitch()

SoundSource Component

تشغيل مؤثرات الصوتيه او الموسيقى

المتغيرات

اسم المتغير النوع الوصف
sound string اسم الصوتيه لجلب ملف sound.mp3/wav وتشغيل الصوت
playOnStart bool يقوم بتشغيل الصوتيه عند بدء المشهد

الدوال

الدالة الوصف
Play() تشغيل الصوت الحالية
Stop() ايقاف الصوت الحالي بشكل نهائي
Pause() ايقاف مؤقت للصوت الحالي فيما بعد
Resume() عودة تشغيل الصوت الحالي كايقاف مسبق
SetPitch(float pitch) تعيين سرعة الصوت
SetVolume(float volume) تعيين مستوى الصوت ما بين 0 و 1
SetLoop(bool loop) تعيين دوارن تشغيل الصوت بشكل لا نهاية الا عند الانتهى المشهد
GetPitch() يجلب سرعة الصوت
GetVolume() يجلب مستوى الصوت
IsLooping() يجلب ما اذا كان التشغيل الانهاية قيد التشغيل
IsPlaying() يجلب ما اذا كان الصوتيه قيج التشغيل
IsPaused() يجلب ما اذا كان تم ايقاف المؤقت للصوتيه
