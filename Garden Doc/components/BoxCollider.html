BoxCollider Component

Physics body in world on shape Box Collider

Properties

Name Type Description
center Vec2 offset shape collider in world
size Vec2 size shape collider in world
isTrigger bool check in shape collider if collision with other shape collider, and not manifold
density float mass Physics body in world by gram wighet
friction float amount friction between two body
restitution float how force is the reverse rebound
restitutionThreshold float the recoil force itself
OnTriggerEnter function when another collider begins to enter itself so calls the function
OnTriggerExit function when another collider to exit from itself so calls the function

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new BoxCollider component at . center, size, isTrigger.
local collider = entity:AddComponent(BoxCollider(vec2(16, 16), vec2(1, 1), false))

-- access the BoxCollider properties
collider.center = vec2(16, 32)
collider.size = vec2(1.0, 0.5)
collider.isTrigger = true
collider.density = 1.0

collider.OnTriggerEnter = function(other)
    DebugLog("is enter collider : ", other:name())
end

BoxCollider Component

جسم فيزيائي يمثل شكلة ليتصادم مع اجسام اي يكن شكله

المتغيرات

اسم المتغير النوع الوصف
center Vec2 موقع الكولايدر في العالم
size Vec2 حجم الكولايدر
isTrigger bool عند تفعيله يصبح لا تاثر فزيائي فقد لكشف اذا كان اي كائن دخل او خرج من ملامسته
density float يمثل كثافة او وزن الجسم
friction float مدى قوة احتكاك جسم اخر
restitution float مدى الارتداد بعد تصادم مع كائن اخر وانعكاس القوى
restitutionThreshold float مدى قوة الانعكاس الصادر من الارتداد نفسه
OnTriggerEnter function عند بداية دخول جسم اخر يستدعي الدالة
OnTriggerExit function عند خروج الجسم الاخر بعد دخوله يستدعي الدالة
