TextWorld Component

text with out canvas free transform in world

Properties

Name Type Description
font string font name for get font.ttf and change font style
text string write text to view in world
fontSize int font size in world
padding int set padding between words
wrap int set wrap to padding between lines
color Color color text view in world

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new TextWorld component at . font, text, fontSize, padding, wrap, color.
local textWorld = entity:AddComponent(TextWorld("none", "Hello World!", 16, 3, 1, Color(255, 255, 0, 255)--yellow))

-- access the TextWorld properties
textWorld.text = "Hello Developer!"
textWorld.fontSize = 24
textWorld.color = Color(0, 0, 255, 255)--blue

TextWorld Component

لعرض نص معين في موقع الكائن. له الحرية في اي مكان في العالم عكس نص القائمة يبقى مربوط مع الكاميرا

المتغيرات

اسم المتغير النوع الوصف
font string اسم font ياتي بي ملف font.ttf. لتغير شكل النص المعروض
text string تعيين النص المعروض في العالم
fontSize int حجم النص
padding int تعيين مسافة ما بين الحروف
wrap int تعيين المسافة ما بين الاسطر
color Color لون النص المعروض في العالم
