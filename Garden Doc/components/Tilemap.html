Tilemap Component

make custom map by tiles

Properties

Name Type Description
texture string name texture or image.png/.jpg to split texture to textures for all tiles
layer int high layer up on low layer
collider bool every tile special box collider

Functions

Function Description
GetTransformBodies() Return all transforms bodies or all box colliders for every tiles

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new Tilemap component at . texture, layer, collider.
local tilemap = entity:AddComponent(Tilemap("tilemap.png", -1, false))

-- access the Tilemap properties
tilemap.texture = "tilemap2.png"
local transformsBodies = tilemap:GetTransformBodies()

المتغيرات

اسم المتغير النوع الوصف
texture string اسم الصورة لجلب ملف texture.png/jpg. تقسيم الصورة لمجموعة صور كل tile له صوره. ويتكون tiles
