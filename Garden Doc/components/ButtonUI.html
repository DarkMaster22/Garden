ButtonUI Component

button haved event if Clicked get function onclick for user interface

Properties

Name Type Description
color Color normal color button
color_hoverd Color if mouse up button to change hoverd color
color_disabled Color when end pressed button change disabled color
OnClick function On Pressed Button get event from function

Example


-- Create a new entity
local entity = Entity("name", "group")

-- Add a new ButtonUI component at color, color_hoverd, color_disabled. 
local button = entity:AddComponent(ButtonUI(Color(255, 255, 255, 255), Color(255, 255, 0, 255), Color(255, 0, 0, 255)))

-- access the ButtonUI properties
button.color = Color(128, 128, 128, 255)--Gray
button.OnClick = function()
    DebugLog("button is clicked!")
end

ButtonUI Component

ازرار لتسهيل استخدام واجهة المستخدم عند ضغط الزر يستدعي الدالة OnClick

المتغيرات

اسم المتغير النوع الوصف
color Color الون المعتاد للزر
color_hoverd Color الماوس فوق الزر يغير الى هذا الون
color_disabled Color يتغير الون لحضة ضغط الزر
OnClick function عند ضغط الزر يستدعي الدالة
