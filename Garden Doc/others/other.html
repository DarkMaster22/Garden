Functions

Function Description
DeltaTime() return value float ms time per frame
LoadScene(string) to switch other scene by name
ScreenCoordsToWolrd(Vec2) calculate Vec2 from Screen coords to World coords for activate in world not just in screen
WorldCoordsToScreen(Vec2) calculate Vec2 from World coords to Screen coords for activate in screen not just in world
LoadScript(string) to get script file.lua and read by name
DebugLog(Args) send massage to consale logger if need something
DebugWarn(Args) send massage ALert to consale logger if need edit thing
DebugError(Args) send msg Error to consale logger

Example


LoadScript("Player.lua")
LoadScene("Level 1.gge")
local framerate = 1 / DeltaTime()
DebugLog("fps : ", framerate)

الدوال

الدالة الوصف
DeltaTime() جلب وقت الذي يمر كل اطار اجزاء من الثانيه
LoadScene(string) انتقال الى مشهد اخر من اسمه
ScreenCoordsToWolrd(Vec2) تحويل المتجه من الشاشة الى عالم العبة
WorldCoordsToScreen(Vec2) تحويل المتجه من عالم العبة الى الشاشة
LoadScript(string) لقراة ملف script.lua
DebugLog(string) بعث رسالة الى المحرك
DebugWarn(string) بعث رسالة تحذيريه الى المحرك
DebugError(string) بعث رسالة هناك خطاء في الكود للتحقق منه
