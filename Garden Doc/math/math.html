Functions

Function Description
Distance(Vec2 a, Vec2 b) return value distance between a and b
Distance(Vec3 a, Vec3 b) return value distance between a and b
Distance(Vec4 a, Vec4 b) return value distance between a and b
MoveTo(Vec2 a, Vec2 b, float time) return value for move a go to b on smooth
MoveTo(Vec3 a, Vec3 b, float time) return value for move a go to b on smooth
MoveTo(Vec4 a, Vec4 b, float time) return value for move a go to b on smooth
Lerp(float a, float b, float time) return value add a to b on smooth
Clamp(float value, float min, float max) return value clamp between on little min and mush max

Example


local a = Vec2(50, 30)
local b = Vec2(32, 16)

a.x = Lerp(a.x, b.x, 3)

if Distance(a, b) < 16 then
    a = MoveTo(a, b, 5 * DeltaTime())
end

a.x = Clamp(a.x, 0, 10)
