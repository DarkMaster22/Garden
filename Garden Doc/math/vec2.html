Vec2

Vec2 have 2 bat type float x and y for make point in space have length and direction

Properties

Name Type Description
x float every plus go right and every sub go left
y float every plus go down and every sub go up

Functions

Function Description
length() return direction length
lengthSq() return sqrt direction length
dot(Vec2) return float a.b
Normalize() return Vec2 Normalized

Example


local a = Vec2(50, 30)
local b = Vec2(32, 16)

a:Normalize()

local dot = a:dot(b)

local distance = a - b
local length = distance:length()

local between = b * 4

Vec2

المتجه هو عباره عن نقطة في الفضاء له x-y يعبرعن موقعة ولكن له طول واتجاه

المتغيرات

اسم المتغير النوع الوصف
x float كل ما زاد بشكل موجب ذهب يمين اكثر وكل ما اصبح اقل من الصفر واصبح سلبي اكثر ذهب لليسار (-x____________0___________x+)
y float كل ما زاد بشكل موجب ذهب للاسفل وكل ما اصبح اقل من الصفر واصبح اقل سلبي ذهب للاعلى

الدوال

الدالة الوصف
length() يعيد قيمه طول اتجاه المتجه
lengthSq() يعيد قيمة جذر التكعيبي لطول اتجاه المتجه
dot(Vec2) يعيد قيمة اسقاط متجه اخر على المتجه
Normalize() يعيد قيمة الاتجاه ناعم ما بين الصفر والواحد 0-1

مثال


local a = Vec2(50, 30)
local b = Vec2(32, 16)

a:Normalize()

local dot = a:dot(b)

local distance = a - b
local length = distance:length()

local between = b * 4-- يتيح ضرب اتجاهين بي بعضم البعض وضرب اتجاه برقم
