Vec3

Vec3 have 3 bat type float x and y and z for make point in space have length and direction

Properties

Name Type Description
x float every plus go right and every sub go left
y float every plus go down and every sub go up
z float every plus go depth in camera and every sub go big range camera

Functions

Function Description
length() return direction length
lengthSq() return sqrt direction length
dot(Vec3) return float a.b
Normalize() return Vec3 Normalized

Example


local a = Vec3(50, 30, 80)
local b = Vec3(32, 16, 8)

a:Normalize()

local dot = a:dot(b)

local distance = a - b
local length = distance:length()

local between = b * 4

Vec3

المتجه هو عباره عن نقطة في الفضاء له x-y-z يعبرعن موقعة ولكن له طول واتجاه

المتغيرات

اسم المتغير النوع الوصف
x float كل ما زاد بشكل موجب ذهب يمين اكثر وكل ما اصبح اقل من الصفر واصبح سلبي اكثر ذهب لليسار (-x____________0___________x+)
y float كل ما زاد بشكل موجب ذهب للاسفل وكل ما اصبح اقل من الصفر واصبح اقل سلبي ذهب للاعلى
z float كل ما زاد بشكل موجب اصبح بعيد وكل ما اصبح اقل من الصفر واصبح اقل سلبي تقرب للكاميرا

الدوال

الدالة الوصف
length() يعيد قيمه طول اتجاه المتجه
lengthSq() يعيد قيمة جذر التكعيبي لطول اتجاه المتجه
dot(Vec3) يعيد قيمة اسقاط متجه اخر على المتجه
Normalize() يعيد قيمة الاتجاه ناعم ما بين الصفر والواحد 0-1

مثال


local a = Vec3(50, 30, 80)
local b = Vec3(32, 16, 8)

a:Normalize()

local dot = a:dot(b)

local distance = a - b
local length = distance:length()

local between = b * 4-- يتيح ضرب اتجاهين بي بعضم البعض وضرب اتجاه برقم
