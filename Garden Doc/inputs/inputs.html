Inputs

Input keyboard and mouse and Control Gamepad to events

Functions

Function Description
GetKeyDown(Keys key) check key if pressed
GetKeyUp(Keys key) check key if up press
GetMouseButtonDown(MouseButton button) check mouse if pressed the button
GetMouseButtonUp(MouseButton button) check mouse if up press the button
GetGamepadButtonDown(GamepadButton button) check gamepad if up press the button
GetMousePosition() return value Vec2 mouse position in screen
GetMouseScroller() return Vec2 value mouse scroller
GetGamepadName(int id) return string gamepad name
GetGamepadAxis(int id, GamepadAxis axis) return gamepad axis float value between from -1 to 1

Example


if Inputs.GetKeyDown(Keys.W) then
    DebugLog("Key (W) is pressed!")
end

local mousePosition = Inputs.GetMousePosition()

Inputs

ادارة الادخال للتحكم مثل لوحة المفاتيح والماوس او يد كنترولر

الدوأل

الدالة الوصف
GetKeyDown(Keys key) اذا ضغط زر معين في لوحة المفاتيح
GetKeyUp(Keys key) اذا لا يتم الضغط زر معين في لوحة المفاتيح
GetMouseButtonDown(MouseButton button) اذا ما تم ضغط زر معين في الماوس او الفاره
GetMouseButtonUp(MouseButton button) اذا لا يتم ضغط الزر معين في الماوس او الفاره
GetGamepadButtonDown(GamepadButton button) اذا ما تم ضغط زر في يد الكنترولر
GetMousePosition() يجلب قيمة من نوع Vec2 وهي موقع الماوس او الفاره في الشاشة
GetMouseScroller() يجلب قيمة من نوع Vec2 لي اتجاه العجل المجود في الماوس او الفاره
GetGamepadName(int id) يجلب اسم يد الكنترولر من id
GetGamepadAxis(int id, GamepadAxis axis) يعيد قيمة ما بين -1 الى 1 من القير الموجود في يد الكنترولر يحمل id

مثال


if Inputs.GetKeyDown(Keys.W) then
    DebugLog("Key (W) is pressed!")
end

local mousePosition = Inputs.GetMousePosition()
