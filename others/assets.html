Assets

add any asset in resources

Functions

Function Description
addTexture(string textureName, string filepath) add asset from type Texture by name, read file types .png/.jpg, to use render in world
addSound(string soundName, string filepath) add asset from type Sound by name, read file types .mp3/.wav, to use soundsource
addFont(string fontName, string filepath) add asset from type Font by name, read file type .ttf, to render text from font type in world

Example


--add texture
Assets.addTexture("playerTex", "Assets/textures/player.png")
--add sound
Assets.addSound("coinSfx", "Assets/sounds/take coin.wav")
--add font
Assets.addFont("font", "Assets/fonts/arial.ttf")

الدوال

الدالة الوصف
addTexture(string textureName, string filepath) اضافة عنصر من نوع صورة واسم العنصر وموقع الملف من نوع .png/.jpg
addSound(string soundName, string filepath) اضافة عنصر من نوع صوتيه واسم العنصر وموقع الملف من نوع .mp3/.wav
addFont(string fontName, string filepath) اضافة عنصر من نوع الخط واسم العنصر وموقع الملف من نوع .ttf

مثال


--اضافة صورة
Assets.addTexture("playerTex", "Assets/textures/player.png")
--اضافة صوتيه
Assets.addSound("coinSfx", "Assets/sounds/take coin.wav")
--اضافة خط
Assets.addFont("font", "Assets/fonts/arial.ttf")
