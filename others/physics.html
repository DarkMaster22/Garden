Physics

Physics for make real world gravity rigidbody and need Mathmatic to complate

Functions

Function Description
AABB(Vec2 posA, Vec2 scaleA, Vec2 posB, Vec2 scaleB) active if collision a, b by box shape
CircleVsCircle(Vec2 posA, float radiusA, Vec2 posB, float radiusB) active if collision a, b by circles shape
PolygonVsPolygon(Vec2[] verticesA, Vec2[] verticesB) active if collision a, b by vertices for polygon shape
CircleVsPolygon(Vec2[] vertices, Vec2 circlePosition, float circleRadius) active if collision a, b by vertices for polygon shape and with cirlce shape

Example


if AABB(Vec2(0, 0), Vec2(32, 32), Vec2(30, 30), Vec2(16, 16)) then
    DebugLog("Is boxs collision!")
end

if CircleVsCircle(Vec2(50, 50), 16, Vec2(100, 100), 32) then
    DebugLog("Is circles collision!")
end

local vertices = {}--make array from Vec2[]

table.insert(vertices, Vec2(0, 0))
table.insert(vertices, Vec2(50, 50))

if CircleVsPolygon(vertices, Vec2(50, 50), 16) then
    DebugLog("Is circle with polygon collision!")
end

الدوال

الدالة الوصف
AABB(Vec2 posA, Vec2 scaleA, Vec2 posB, Vec2 scaleB) كشف اذا كان هناك تصادم ما بين المربعين a و b
CircleVsCircle(Vec2 posA, float radiusA, Vec2 posB, float radiusB) كشف التصادم ما بين دائرتين
PolygonVsPolygon(Vec2[] verticesA, Vec2[] verticesB) كشف التصادم ما بين شكلين مختلفين
CircleVsPolygon(Vec2[] vertices, Vec2 circlePosition, float circleRadius) كشف التصادم الدائره بي شكل مختلف
