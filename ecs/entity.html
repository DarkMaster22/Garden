Entity Registry

Entity

entity have components in the world

Properties

Name Type Description
name string entity name
group string join entity on group have entities
id int32_t return entity id

Functions

Function Description
AddComponent(Component()) add component for entity
HasComponent(Component()) check if entity haved this component
GetComponent(Component) return component from entity
RemoveComponent(Component) remove or destroy component in this entity
Destroy() destroy the entity

Example


-- Create a new entity
local entity = Entity("name", "group")

-- access the Entity properties
DebugLog("entity name : ", entity:name())

local sprite = entity:AddComponent(Sprite("none", 0, false, Color(255, 255, 255, 255)--white))

local transform = entity:GetComponent(Transform)

entity:Destroy()

Entity - الكائن

كائن له اسم ويحمل مكونات والمحرك يتفاعل مع جميع الكائنات بمكوناتها

المتغيرات

اسم المتغير النوع الوصف
name string اسم الكائن يفضل دائما لكل كائن اسم مختلف
group string اسم قروب يجمع الكائنات تحمل اسم هذا القروب
id int32_t لكل كائن id خاص به

الدوال

الدالة الوصف
AddComponent(Component()) اضافة مكون معين ليحمله الكائن
HasComponent(Component()) يتاكد اذا كان هذا الكائن يحمل مكون معين ام لا
GetComponent(Component) بجلب المكون الذي يحمله الكائن
RemoveComponent(Component) يحذف المكون من الكائن بشكل نهائي
Destroy() يحذف الكائن نهائي

مثال


-- انشاء كائن جديد
local entity = Entity("name", "group")

-- access the Entity properties
DebugLog("entity name : ", entity:name())

local sprite = entity:AddComponent(Sprite("none", 0, false, Color(255, 255, 255, 255)--white))

local transform = entity:GetComponent(Transform)
